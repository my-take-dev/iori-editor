# IORI (庵) Editor

## 命名の由来
**IORI** は **"IO no Ri" (IOの理)** を意味しています。
また、**「庵 (Iori)」**（世俗を離れた隠遁者の住まい、草庵）という意味も込められており、開発者が静かにコードと向き合い、AIと共に創造に没頭できる「知の隠れ家」としての空間を提供します。

Input/Outputの理（ことわり）を追求し、AIとの対話を通じて新しい価値を出力する場となることを目指しています。

## アプリケーション概要
IORIは、**AI CLIツール（Claude Code, Gemini CLI, Codexなど）との協働に特化したデスクトップIDE**です。

従来のIDEは「人間がコードを書く」ことを主眼に置いていますが、IORIは「AIがコードを書き、人間がそれを監督・修正・承認する」という新しい開発フローに最適化されています。

### 主な特徴

1.  **AI CLI特化のデュアルターミナル**
    *   **AI AGENTターミナル**: AIツールを実行するための専用ターミナル。
    *   **USER SHELL**: ユーザーがコマンドを実行するためのターミナル。
    *   これらを並列（Split）またはタブで切り替えながら、AIへの指示と自身の作業をシームレスに行えます。

2.  **マルチセッション・ワークツリー管理**
    *   複数のプロジェクトや、同一リポジトリの異なるGit Worktreeを「セッション」として並列管理。
    *   AIに別ブランチでタスクを依頼しながら、自分はメインブランチで作業するといった並行開発が容易になります。

3.  **リアルタイムDiff & エディタ**
    *   AIがファイルを変更すると、即座にDiff（差分）ビューで確認可能。
    *   変更内容をSide-by-Sideで確認し、Accept（承認）/ Reject（却下）を選択、あるいは直接手動で修正してコミットできます。
    *   Monaco Editorを採用し、高速で快適な編集体験を提供します。

4.  **シンプル & 高速**
    *   Wails (Go + React) で構築された軽量なネイティブアプリ。
    *   プラグインシステムを排除し、必要な機能（Git操作、ターミナル、エディタ）のみを統合。
    *   Windows環境（Win32 API活用）に最適化。

### 想定ユースケース
*   **AI駆動開発**: Claude CodeなどのCLIツールを常駐させ、自然言語でコーディングを依頼しつつ、人間はレビューと微修正に徹する。
*   **並行タスク処理**: バグ修正をAIに任せている間に、別の機能実装を別セッションで進める。
*   **実験的コーディング**: 既存コードを壊さずに、Worktreeを使った別環境でAIに大胆なリファクタリングを試させる。

個人開発をするための個人開発エディタです。
自身で作ることによる社用利用可能な、気軽なToolとしての立ち位置です。

実態は、いい感じにターミナルを何個か起動して、あっちこっちからcli系Toolを動かすだけです。

- 機能
  - 複数フォルダ指定作業
  - 指定フォルダ,指定ブランチからのworktreeセッション対応
  - 作業中、選択中を視覚的に表示
    - 待機中：黄色
    - 動作中：緑色
    - 選択中：青色
  - github連携
    - pull
    - push
    - その他ブランチ生成、コミット等
  - 簡易エディタ機能
    - ちょっとした確認用
  - DIFF表示機能
  - 会話履歴参照機能
    - ログはexe起動元直下
  - ブラウザモード
    - アプリ上からserverモードを起動するとブラウザで簡易開発が別軸で可能
    - 非同期の為、依頼→切断→確認が可能
    - worktree生成～削除、個別セッション切断まで可能
    - mdのみ参照できるエクスプローラー付き
      - ※　タスクが既にmdにあって投げる為用


- 開発
    - 9割をClaude code,1割をcodex cliにて実装(人は動作確認のみ)
